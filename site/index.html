How it works

From your domain name to a fix list, in four steps

Hejnal sends what any visitor sends. It never logs in, never tries an exploit, and only checks systems you have authorised in writing.

01
Discover

Find what you expose

Domains, subdomains from public certificate logs, IP ranges and the ports that answer.

02
Identify

Recognise the software

279 products from web pages and service greetings: VPNs, firewalls, routers, cameras, mail servers, CMSs, developer tools.

03
Match

Check what attackers exploit

CISA's catalog of exploited flaws, NVD version ranges and FIRST exploit likelihood, every morning.

!
Alert

Tell you what to fix first

A ranked fix list in English or Polish, alerts in Slack, Teams or email, a REST API and an MCP server for AI agents.
