How it works

One ordinary visit per system, three questions answered

Hejnal sends what any visitor sends. It never logs in, never tries an exploit, and only checks systems you have authorised in writing.

  1. Find what you expose

    Your domains, subdomains from public certificate logs, your IP ranges and the ports that answer.

  2. Recognise the software

    279 products, from VPN gateways and firewalls to routers, cameras, mail servers, CMSs and developer tools, read from web pages and service greetings.

  3. Match what attackers exploit

    CISA's catalog of exploited flaws, version ranges from NVD and exploit likelihood from FIRST, ranked into a weekly fix list and alerts within hours.

Built to be trusted

Safe by design, traceable by default

Detection only

No exploits, no logins, no brute force. Optional checks only look for exposed files such as .env and .git.

Every finding has a source

Each item links to the catalog entry, the version check and the evidence Hejnal saw, so you can verify it yourself.

Written authorisation

Every scope file records who approved the scan and when. Hejnal refuses targets outside it.

Signed, open releases

Open-source code, signed builds and a list of every component, because security tools are targets too.
